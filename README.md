# MSB BHS Results Portal

Static pages for MSB BHS Educational Institute results. Marks are read live from the
school's results Apps Script (JSON API), fetched without Google sign-in so the pages
work on phones signed into several Google accounts.

| Page | For | What it does |
|---|---|---|
| `index.html` | Parents | Report card by class + ITS number (classes 5-12) |
| `conduct.html` | Parents | Hasanaat / Tanbeeh log, opened from the card's Conduct mark |
| `print.html` | Class teachers, HOS | Whole class or whole school as one PDF (staff PIN) |
| `bhs/di.html`, `bhs/exacts.html` | Parents | BHS (classes 1-4) report cards |
